## Story

**As a** user who checks weather for more than one city, **I want to** save
cities I check often **so that** I can switch between them quickly without
re-typing or re-searching each time.

**Acceptance criteria (GWT):**
- AC-1: Given I am viewing the weather for a city, when I tap a Save/star icon, then that city is added to my saved list and the icon reflects saved state.
- AC-2: Given I have one or more saved cities, when I open the saved-cities list, then I see each saved city's name and current temperature/condition.
- AC-3: Given I have a saved city selected in the list, when I tap it, then the app loads that city's full weather view using its stored coordinates (not a re-geocoded name lookup).
- AC-4: Given I have a saved city, when I tap Remove/un-star it, then it is removed from the saved list and localStorage with no page reload required.
- AC-5: Given I have no saved cities, when I open the saved-cities list, then I see an empty-state message inviting me to save one.
- AC-6: Given localStorage is unavailable or full, when I try to save a city, then the app shows a non-blocking error and the current city view still works normally.
